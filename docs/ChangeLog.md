# ChangeLog

## 2026-10-05 客户端断开即取消节点生成、记录客户端标识

- 起因：客户端的自动安全审查发出非流式请求（思考上限 16000），本地模型要几分钟才返回，客户端约 20~25 秒超时重发。入口在节点返回前不看客户端连接，放弃的请求一直占着节点，两台节点排队 3~6 个，正常会话也被拖住。
- 转发生成请求期间每秒检查一次客户端连接：可读却读到 0 字节即视为已断开，断开到节点的连接，Strata 随之取消生成（它自己也按同样方式监视连接）。这样的请求记为“客户端断开”、状态码 499，不再被当成节点故障去标记离线或换节点重试。
- 请求表新增 `client` 列，记录 User-Agent（前 200 字符，旧库启动时自动补列）。请求页、总览“最近请求”、节点详情“路由记录”新增“客户端”列，显示产品名与版本（如 claude-cli 2.1.3），悬停或打开请求详情可看完整 User-Agent。
- 新增 3 个测试（客户端断开时节点被取消且不算离线、记录 User-Agent、旧库补列），共 33 个。

## 2026-10-04 Responses 接口改为原生直通

- Strata 0.1.39 起节点原生支持 `/v1/responses`，入口不再转换成 Chat Completions，改为把请求原样转发给节点、响应原样回给客户端；删除 `responses.py` 转换模块。
- 会话识别、固定前缀估算、请求预览按 Responses 格式读取 `instructions` 与 `input`；用量解析支持 Responses 的 `usage`（含 `response.completed` 事件）；首字延迟按第一个 delta 事件计算。
- 转换相关的 4 个测试换成 3 个直通测试（原样转发与用量、流式首字延迟、会话识别），共 30 个。

## 2026-10-04 支持 Responses 接口，改名 Strata Router

- 新增 `/v1/responses`（OpenAI Responses 协议）：新模块 responses.py 把请求转成 Chat Completions 发给节点，再把结果与流式分块转回 Responses 格式（参考 new-api apicompat 的反向实现），支持思考摘要、工具调用、结构化输出、用量与缓存命中。不支持 `previous_response_id`。
- 请求日志记录协议为 responses，控制台请求详情显示“Responses”；Responses 流式的首字延迟按第一个实际增量计算。
- 控制台品牌、页面标题与文档中的 “Strata Cluster” 改为 “Strata Router”，启动日志同步改名。
- 新增 4 个测试（请求转换、非流式、流式事件序列、拒绝 previous_response_id），共 26 个全部通过；用 openai SDK 经临时入口对 win3080 实测非流式、流式、工具调用与回传工具结果均正常。
